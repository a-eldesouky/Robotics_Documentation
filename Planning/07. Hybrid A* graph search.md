# Hybrid A*: A Complete Technical Guide from Classical A* to Vehicle-Aware Path Planning

## 1. Introduction

Classical path planning algorithms such as **BFS**, **DFS**, **Uniform Cost Search / Dijkstra**, and **A*** are usually introduced in the context of graph search or grid-based robot navigation. They are excellent for understanding how a robot can search through a map to find a path from a start position to a goal position.

However, these algorithms usually assume that the robot can move freely from one grid cell to another. For example, a normal A* planner may allow movement:

```cpp
up
down
left
right
```

or sometimes:

```cpp
up
down
left
right
diagonal directions
```

This is acceptable for an abstract point robot, but it is not realistic for many real robots.

A **car-like robot** cannot move sideways. It cannot instantly rotate in place. It has a steering limit, a wheelbase, and a minimum turning radius. Therefore, a path generated by normal A* may be geometrically short but physically impossible for the robot to follow.

**Hybrid A*** solves this problem.

Hybrid A* extends classical A* by adding the robot’s orientation and kinematic constraints into the search process. Instead of searching only over:

```cpp
x, y
```

Hybrid A* searches over:

```cpp
x, y, theta
```

where `theta` is the robot’s heading.

So Hybrid A* is still an A*-based planner, but it expands nodes using **vehicle motion simulation** instead of simple grid neighbors.

---

## 2. The Motivation Behind Hybrid A*

### 2.1 Classical A*

Normal A* searches over discrete grid cells.

A node usually represents:

```cpp
(row, col)
```

or:

```cpp
(x, y)
```

The planner maintains a priority queue and chooses the next node based on:

```cpp
f(n) = g(n) + h(n)
```

where:

```cpp
g(n) = cost from start to current node
h(n) = estimated cost from current node to goal
f(n) = total priority score
```

In your reference ROS 2 A* implementation, the planner:

* subscribes to `/map`
* listens to `/goal_pose`
* gets the robot pose from TF
* converts the robot pose and goal pose from world coordinates to grid coordinates
* expands 4-connected grid neighbors
* uses Manhattan distance as the heuristic
* reconstructs the path using parent pointers
* publishes the path and a visited map 

The core of the original A* planner is:

```cpp
GraphNode start_node = worldToGrid(start);
GraphNode goal_node = worldToGrid(goal);
start_node.heuristic = manhattanDistance(start_node, goal_node);
```

and the neighbor expansion is:

```cpp
std::vector<std::pair<int, int>> explore_directions = {
    {-1, 0}, {1, 0}, {0, -1}, {0, 1}
};
```

This means the robot moves from one grid cell to another.

---

### 2.2 Why Classical A* Fails for Car-Like Robots

A* may produce a path like:

```cpp
go straight
turn sharply
move sideways
turn instantly
```

This is acceptable on a grid, but not for a car-like robot.

A car-like robot has **non-holonomic constraints**.

A non-holonomic robot cannot freely move in every direction. For example, a car cannot directly move sideways. It must move forward or backward while turning.

So even if normal A* finds the shortest grid path, that path may be:

```cpp
geometrically valid
but physically infeasible
```

Example:

A* may say:

```cpp
the goal is directly to the left
so move left
```

But a car-like robot cannot move left directly. It must turn and follow an arc.

This is the core reason Hybrid A* exists.

---

## 3. Definition of Hybrid A*

**Hybrid A*** is a search-based path planning algorithm that extends A* from a 2D grid space into a continuous pose space.

Instead of planning over:

```cpp
(x, y)
```

it plans over:

```cpp
(x, y, theta)
```

where:

```cpp
x     = robot position in the world
y     = robot position in the world
theta = robot heading angle
```

Hybrid A* is called “hybrid” because it combines:

| Component          | Meaning                                             |
| ------------------ | --------------------------------------------------- |
| Continuous motion  | Robot states use real-valued `x`, `y`, and `theta`  |
| Discrete search    | States are stored using grid cells and heading bins |
| A* logic           | Nodes are selected using `f = g + h`                |
| Vehicle kinematics | Expansion follows a bicycle/car-like model          |

So Hybrid A* keeps the search structure of A*, but replaces grid-neighbor expansion with physically feasible motion primitives.

---

## 4. Dijkstra, A*, and Hybrid A*

### 4.1 Dijkstra / Uniform Cost Search

Dijkstra’s algorithm, also called Uniform Cost Search in many AI contexts, finds shortest paths by expanding nodes according to accumulated cost only:

```cpp
f(n) = g(n)
```

It does not use a heuristic.

Dijkstra is useful when the goal may be unknown or when the planner needs shortest paths to many nodes.

Conceptually, Dijkstra propagates outward from the start like a wave.

It finds the shortest path tree from the start to all reachable nodes.

---

### 4.2 A*

A* improves Dijkstra by adding a heuristic:

```cpp
f(n) = g(n) + h(n)
```

The heuristic guides the search toward the goal.

For a grid map, common heuristics are:

```cpp
Manhattan distance
Euclidean distance
Diagonal distance
```

For example:

```cpp
h = abs(x_goal - x) + abs(y_goal - y)
```

or:

```cpp
h = sqrt((x_goal - x)^2 + (y_goal - y)^2)
```

A* is usually faster than Dijkstra because it does not expand uniformly in all directions. It expands toward the goal.

---

### 4.3 Heuristic Admissibility

A heuristic is **admissible** if it never overestimates the true cost to the goal.

In simple terms:

```cpp
h(n) <= true_cost_to_goal
```

Why does this matter?

Because if the heuristic overestimates, A* may ignore the best path and return a suboptimal result.

For grid A*, Euclidean distance is often admissible because the true path cannot be shorter than the straight-line distance.

For Hybrid A*, however, Euclidean distance is weak because it ignores orientation and turning radius.

That is why Hybrid A* often uses non-holonomic heuristics such as:

```cpp
Dubins distance
Reeds-Shepp distance
```

---

## 5. Core Idea of Hybrid A*

Normal A* node:

```cpp
GraphNode(x, y)
```

Hybrid A* node:

```cpp
HybridNode(x, y, theta)
```

Normal A* expansion:

```cpp
up
down
left
right
```

Hybrid A* expansion:

```cpp
forward-left
forward-straight
forward-right
```

If reverse is allowed:

```cpp
reverse-left
reverse-straight
reverse-right
```

So instead of moving between grid neighbors, Hybrid A* simulates short vehicle motions.

---

## 6. Vehicle Kinematics: Bicycle Model

Hybrid A* commonly uses the bicycle model.

The robot state is:

```cpp
x, y, theta
```

A motion primitive uses:

```cpp
ds     = distance traveled
delta  = steering angle
L      = wheelbase
```

The update equations are:

```cpp
x_next = x + ds * cos(theta)
y_next = y + ds * sin(theta)
theta_next = theta + ds / L * tan(delta)
```

where:

```cpp
L     = wheelbase
delta = steering angle
ds    = traveled distance
```

### 6.1 What Is the Wheelbase?

The wheelbase is the distance between the rear axle and the front axle of a car-like vehicle.

In the bicycle model, the car is simplified into:

```cpp
one virtual rear wheel
one virtual front wheel
```

The distance between these two virtual wheels is the wheelbase.

A larger wheelbase means the robot turns more slowly.

A smaller wheelbase means the robot can turn more sharply.

Example:

```cpp
ds = 0.25
delta = 0.6 rad
L = 0.5
```

Then:

```cpp
theta_change = ds / L * tan(delta)
theta_change = 0.25 / 0.5 * tan(0.6)
theta_change ≈ 0.342 rad
```

That is about:

```cpp
19.6 degrees
```

If the wheelbase becomes:

```cpp
L = 1.0
```

then:

```cpp
theta_change = 0.25 / 1.0 * tan(0.6)
theta_change ≈ 0.171 rad
```

That is about:

```cpp
9.8 degrees
```

So increasing the wheelbase reduces the heading change for the same steering command.

---

## 7. Minimum Turning Radius

The minimum turning radius is computed from the wheelbase and maximum steering angle:

```cpp
R_min = L / tan(delta_max)
```

where:

```cpp
R_min     = minimum turning radius
L         = wheelbase
delta_max = maximum steering angle
```

In code:

```cpp
double min_turning_radius_ = wheelbase_ / std::tan(max_steering_angle_);
```

Example:

```cpp
wheelbase_ = 0.5
max_steering_angle_ = 0.6
```

Then:

```cpp
tan(0.6) ≈ 0.684
R_min = 0.5 / 0.684
R_min ≈ 0.731 m
```

This means the robot cannot turn with a radius smaller than approximately:

```cpp
0.73 meters
```

This value is essential for the Dubins heuristic.

---

## 8. Dubins Heuristic

### 8.1 Why Dubins?

A Euclidean heuristic estimates only straight-line distance:

```cpp
h = sqrt((x_goal - x)^2 + (y_goal - y)^2)
```

But a car-like robot cannot always follow the straight line. It must respect:

```cpp
heading
turning radius
forward-only motion
```

Dubins distance estimates the shortest path between two poses assuming:

```cpp
forward-only motion
bounded curvature
minimum turning radius
```

So the Dubins heuristic is much more realistic for forward-only Hybrid A*.

---

### 8.2 Dubins Path Types

A Dubins path is composed of:

```cpp
L = left arc
R = right arc
S = straight segment
```

The shortest Dubins path must be one of six path families:

```cpp
LSL
RSR
LSR
RSL
RLR
LRL
```

The Dubins heuristic is:

```cpp
h_Dubins(s, goal) =
min path length among {LSL, RSR, LSR, RSL, RLR, LRL}
```

---

### 8.3 Meaning of `t`, `p`, and `q`

Each Dubins word function returns:

```cpp
t, p, q
```

For example, for `LSL`:

```cpp
Left turn → Straight → Left turn
```

The values mean:

```cpp
t = first left-turn arc
p = straight segment
q = final left-turn arc
```

The normalized path length is:

```cpp
t + p + q
```

The real-world length is:

```cpp
length = (t + p + q) * R
```

where:

```cpp
R = min_turning_radius
```

Example:

```cpp
t = 1.0
p = 3.0
q = 0.5
R = 0.73
```

Then:

```cpp
length = (1.0 + 3.0 + 0.5) * 0.73
length = 4.5 * 0.73
length = 3.285 m
```

---

## 9. Hybrid A* Full ROS 2 Code with Dubins Heuristic

The following implementation keeps the same high-level architecture as the original ROS 2 A* node:

```cpp
/map subscriber
/goal_pose subscriber
TF lookup for base_footprint
/path publisher
/visited_map publisher
```

But the planning core is changed from grid A* to Hybrid A*.

```cpp
#include <algorithm>
#include <cmath>
#include <functional>
#include <limits>
#include <memory>
#include <queue>
#include <unordered_map>
#include <vector>

#include "rclcpp/rclcpp.hpp"
#include "nav_msgs/msg/occupancy_grid.hpp"
#include "nav_msgs/msg/path.hpp"
#include "geometry_msgs/msg/pose.hpp"
#include "geometry_msgs/msg/pose_stamped.hpp"
#include "geometry_msgs/msg/transform_stamped.hpp"

#include "tf2/utils.h"
#include "tf2/LinearMath/Quaternion.h"
#include "tf2_geometry_msgs/tf2_geometry_msgs.hpp"
#include "tf2_ros/buffer.h"
#include "tf2_ros/transform_listener.h"

#include "rmw/qos_profiles.h"

namespace bumperbot_planning
{

class HybridAStarPlanner : public rclcpp::Node
{
public:
    HybridAStarPlanner() : Node("hybrid_a_star_node")
    {
        tf_buffer_ = std::make_unique<tf2_ros::Buffer>(get_clock());
        tf_listener_ = std::make_shared<tf2_ros::TransformListener>(*tf_buffer_);

        rclcpp::QoS map_qos(10);
        map_qos.durability(RMW_QOS_POLICY_DURABILITY_TRANSIENT_LOCAL);

        map_sub_ = create_subscription<nav_msgs::msg::OccupancyGrid>(
            "/map",
            map_qos,
            std::bind(&HybridAStarPlanner::mapCallback, this, std::placeholders::_1)
        );

        goal_sub_ = create_subscription<geometry_msgs::msg::PoseStamped>(
            "/goal_pose",
            10,
            std::bind(&HybridAStarPlanner::goalCallback, this, std::placeholders::_1)
        );

        path_pub_ = create_publisher<nav_msgs::msg::Path>(
            "/hybrid_a_star/path",
            10
        );

        visited_map_pub_ = create_publisher<nav_msgs::msg::OccupancyGrid>(
            "/hybrid_a_star/visited_map",
            10
        );

        min_turning_radius_ = wheelbase_ / std::tan(max_steering_angle_);

        steering_angles_ = {
            -max_steering_angle_,
             0.0,
             max_steering_angle_
        };

        RCLCPP_INFO(get_logger(), "Hybrid A* planner initialized.");
        RCLCPP_INFO(get_logger(), "Minimum turning radius: %.3f m", min_turning_radius_);
    }

private:
    static constexpr double PI = 3.14159265358979323846;

    struct GridNode
    {
        int x;
        int y;

        GridNode() = default;

        GridNode(int x_, int y_)
            : x(x_), y(y_)
        {}
    };

    struct HybridNode
    {
        double x = 0.0;
        double y = 0.0;
        double theta = 0.0;

        int grid_x = 0;
        int grid_y = 0;
        int theta_bin = 0;

        double cost = 0.0;
        double heuristic = 0.0;

        std::shared_ptr<HybridNode> prev = nullptr;

        HybridNode() = default;

        HybridNode(
            double x_,
            double y_,
            double theta_,
            int grid_x_,
            int grid_y_,
            int theta_bin_)
            : x(x_),
              y(y_),
              theta(theta_),
              grid_x(grid_x_),
              grid_y(grid_y_),
              theta_bin(theta_bin_)
        {}

        double totalCost() const
        {
            return cost + heuristic;
        }
    };

    struct CompareHybridNode
    {
        bool operator()(const HybridNode & a, const HybridNode & b) const
        {
            return a.totalCost() > b.totalCost();
        }
    };

private:
    rclcpp::Subscription<nav_msgs::msg::OccupancyGrid>::SharedPtr map_sub_;
    rclcpp::Subscription<geometry_msgs::msg::PoseStamped>::SharedPtr goal_sub_;

    rclcpp::Publisher<nav_msgs::msg::Path>::SharedPtr path_pub_;
    rclcpp::Publisher<nav_msgs::msg::OccupancyGrid>::SharedPtr visited_map_pub_;

    std::unique_ptr<tf2_ros::Buffer> tf_buffer_;
    std::shared_ptr<tf2_ros::TransformListener> tf_listener_;

    nav_msgs::msg::OccupancyGrid::SharedPtr map_;
    nav_msgs::msg::OccupancyGrid visited_map_;

private:
    int theta_bins_ = 72;

    double step_size_ = 0.25;
    double wheelbase_ = 0.5;
    double max_steering_angle_ = 0.6;

    double min_turning_radius_ = 0.0;

    double goal_xy_tolerance_ = 0.25;
    double goal_theta_tolerance_ = 0.35;

    double turning_penalty_ = 1.2;

    // Forward-only because Dubins assumes forward-only motion.
    std::vector<int> directions_ = {1};

    std::vector<double> steering_angles_;

private:
    void mapCallback(const nav_msgs::msg::OccupancyGrid::SharedPtr map)
    {
        map_ = map;

        visited_map_.header.frame_id = map->header.frame_id;
        visited_map_.info = map->info;
        visited_map_.data = std::vector<int8_t>(
            visited_map_.info.height * visited_map_.info.width,
            -1
        );

        RCLCPP_INFO_ONCE(get_logger(), "Map received.");
    }

    void goalCallback(const geometry_msgs::msg::PoseStamped::SharedPtr goal_pose)
    {
        if (!map_) {
            RCLCPP_ERROR(get_logger(), "No map received yet.");
            return;
        }

        visited_map_.data = std::vector<int8_t>(
            visited_map_.info.height * visited_map_.info.width,
            -1
        );

        geometry_msgs::msg::TransformStamped map_to_base_tf;

        try {
            map_to_base_tf = tf_buffer_->lookupTransform(
                map_->header.frame_id,
                "base_footprint",
                tf2::TimePointZero
            );
        } catch (const tf2::TransformException & ex) {
            RCLCPP_ERROR(
                get_logger(),
                "Could not transform from %s to base_footprint: %s",
                map_->header.frame_id.c_str(),
                ex.what()
            );
            return;
        }

        geometry_msgs::msg::Pose start_pose;
        start_pose.position.x = map_to_base_tf.transform.translation.x;
        start_pose.position.y = map_to_base_tf.transform.translation.y;
        start_pose.position.z = 0.0;
        start_pose.orientation = map_to_base_tf.transform.rotation;

        nav_msgs::msg::Path path = plan(start_pose, goal_pose->pose);

        if (!path.poses.empty()) {
            RCLCPP_INFO(get_logger(), "Hybrid A* path found.");
            path_pub_->publish(path);
        } else {
            RCLCPP_WARN(get_logger(), "Hybrid A* failed to find a path.");
        }
    }

private:
    nav_msgs::msg::Path plan(
        const geometry_msgs::msg::Pose & start,
        const geometry_msgs::msg::Pose & goal)
    {
        std::priority_queue<
            HybridNode,
            std::vector<HybridNode>,
            CompareHybridNode
        > pending_nodes;

        std::unordered_map<std::size_t, double> best_cost;

        double start_theta = tf2::getYaw(start.orientation);
        double goal_theta = tf2::getYaw(goal.orientation);

        GridNode start_grid = worldToGrid(start.position.x, start.position.y);
        GridNode goal_grid = worldToGrid(goal.position.x, goal.position.y);

        HybridNode start_node(
            start.position.x,
            start.position.y,
            start_theta,
            start_grid.x,
            start_grid.y,
            thetaToBin(start_theta)
        );

        HybridNode goal_node(
            goal.position.x,
            goal.position.y,
            goal_theta,
            goal_grid.x,
            goal_grid.y,
            thetaToBin(goal_theta)
        );

        start_node.cost = 0.0;
        start_node.heuristic = hybridHeuristic(start_node, goal_node);

        std::size_t start_index = getHybridIndex(
            start_node.grid_x,
            start_node.grid_y,
            start_node.theta_bin
        );

        pending_nodes.push(start_node);
        best_cost[start_index] = start_node.cost;

        HybridNode active_node = start_node;
        bool found_path = false;

        while (!pending_nodes.empty() && rclcpp::ok()) {
            active_node = pending_nodes.top();
            pending_nodes.pop();

            if (isGoal(active_node, goal_node)) {
                found_path = true;
                break;
            }

            for (int direction : directions_) {
                for (double steering_angle : steering_angles_) {
                    HybridNode new_node = simulateMotion(
                        active_node,
                        steering_angle,
                        direction
                    );

                    GridNode grid_check(new_node.grid_x, new_node.grid_y);

                    if (!poseOnMap(grid_check)) {
                        continue;
                    }

                    if (!isMotionValid(active_node, new_node)) {
                        continue;
                    }

                    double motion_cost = step_size_;

                    if (std::fabs(steering_angle) > 1e-3) {
                        motion_cost *= turning_penalty_;
                    }

                    new_node.cost = active_node.cost + motion_cost;

                    new_node.heuristic = hybridHeuristic(
                        new_node,
                        goal_node
                    );

                    new_node.prev = std::make_shared<HybridNode>(active_node);

                    std::size_t new_index = getHybridIndex(
                        new_node.grid_x,
                        new_node.grid_y,
                        new_node.theta_bin
                    );

                    if (best_cost.find(new_index) == best_cost.end() ||
                        new_node.cost < best_cost[new_index]) {
                        best_cost[new_index] = new_node.cost;
                        pending_nodes.push(new_node);
                    }
                }
            }

            GridNode active_grid = worldToGrid(
                active_node.x,
                active_node.y
            );

            if (poseOnMap(active_grid)) {
                visited_map_.data.at(gridToCell(active_grid)) = -106;
                visited_map_pub_->publish(visited_map_);
            }
        }

        nav_msgs::msg::Path path;
        path.header.frame_id = map_->header.frame_id;
        path.header.stamp = now();

        if (!found_path) {
            return path;
        }

        while (active_node.prev && rclcpp::ok()) {
            geometry_msgs::msg::PoseStamped pose_stamped;
            pose_stamped.header.frame_id = map_->header.frame_id;
            pose_stamped.header.stamp = now();
            pose_stamped.pose = hybridNodeToPose(active_node);

            path.poses.push_back(pose_stamped);

            active_node = *active_node.prev;
        }

        std::reverse(path.poses.begin(), path.poses.end());

        return path;
    }

private:
    HybridNode simulateMotion(
        const HybridNode & current,
        double steering_angle,
        int direction)
    {
        double ds = direction * step_size_;

        double new_x = current.x + ds * std::cos(current.theta);
        double new_y = current.y + ds * std::sin(current.theta);

        double new_theta = current.theta +
            (ds / wheelbase_) * std::tan(steering_angle);

        new_theta = normalizeAngle(new_theta);

        GridNode grid_node = worldToGrid(new_x, new_y);

        HybridNode next(
            new_x,
            new_y,
            new_theta,
            grid_node.x,
            grid_node.y,
            thetaToBin(new_theta)
        );

        return next;
    }

    double hybridHeuristic(
        const HybridNode & node,
        const HybridNode & goal)
    {
        return dubinsDistance(
            node.x,
            node.y,
            node.theta,
            goal.x,
            goal.y,
            goal.theta,
            min_turning_radius_
        );
    }

private:
    bool isGoal(
        const HybridNode & node,
        const HybridNode & goal)
    {
        double dx = goal.x - node.x;
        double dy = goal.y - node.y;

        double position_error = std::sqrt(dx * dx + dy * dy);
        double heading_error = std::fabs(
            normalizeAngle(goal.theta - node.theta)
        );

        return position_error < goal_xy_tolerance_ &&
               heading_error < goal_theta_tolerance_;
    }

    bool isStateValid(double x, double y)
    {
        GridNode grid_node = worldToGrid(x, y);

        if (!poseOnMap(grid_node)) {
            return false;
        }

        std::size_t cell = gridToCell(grid_node);

        if (cell >= map_->data.size()) {
            return false;
        }

        return map_->data.at(cell) == 0;
    }

    bool isMotionValid(
        const HybridNode & from,
        const HybridNode & to)
    {
        int samples = 10;

        for (int i = 0; i <= samples; i++) {
            double t = static_cast<double>(i) / samples;

            double x = from.x + t * (to.x - from.x);
            double y = from.y + t * (to.y - from.y);

            if (!isStateValid(x, y)) {
                return false;
            }
        }

        return true;
    }

private:
    GridNode worldToGrid(double world_x, double world_y)
    {
        int grid_x = static_cast<int>(
            (world_x - map_->info.origin.position.x) /
            map_->info.resolution
        );

        int grid_y = static_cast<int>(
            (world_y - map_->info.origin.position.y) /
            map_->info.resolution
        );

        return GridNode(grid_x, grid_y);
    }

    geometry_msgs::msg::Pose hybridNodeToPose(
        const HybridNode & node)
    {
        geometry_msgs::msg::Pose pose;

        pose.position.x = node.x;
        pose.position.y = node.y;
        pose.position.z = 0.0;

        tf2::Quaternion q;
        q.setRPY(0.0, 0.0, node.theta);
        pose.orientation = tf2::toMsg(q);

        return pose;
    }

    bool poseOnMap(const GridNode & node)
    {
        return node.x >= 0 &&
               node.y >= 0 &&
               node.x < static_cast<int>(map_->info.width) &&
               node.y < static_cast<int>(map_->info.height);
    }

    std::size_t gridToCell(const GridNode & node)
    {
        return static_cast<std::size_t>(
            map_->info.width * node.y + node.x
        );
    }

    std::size_t getHybridIndex(
        int grid_x,
        int grid_y,
        int theta_bin)
    {
        return static_cast<std::size_t>(
            theta_bin * map_->info.width * map_->info.height +
            grid_y * map_->info.width +
            grid_x
        );
    }

private:
    double normalizeAngle(double angle)
    {
        while (angle > PI) {
            angle -= 2.0 * PI;
        }

        while (angle < -PI) {
            angle += 2.0 * PI;
        }

        return angle;
    }

    double mod2pi(double angle)
    {
        double result = std::fmod(angle, 2.0 * PI);

        if (result < 0.0) {
            result += 2.0 * PI;
        }

        return result;
    }

    int thetaToBin(double theta)
    {
        theta = normalizeAngle(theta);

        double shifted_theta = theta + PI;
        double bin_size = 2.0 * PI / static_cast<double>(theta_bins_);

        int bin = static_cast<int>(shifted_theta / bin_size);

        if (bin < 0) {
            bin = 0;
        }

        if (bin >= theta_bins_) {
            bin = theta_bins_ - 1;
        }

        return bin;
    }

private:
    bool dubinsLSL(
        double alpha,
        double beta,
        double d,
        double & t,
        double & p,
        double & q)
    {
        double tmp = d + std::sin(alpha) - std::sin(beta);

        double p_squared =
            2.0 +
            d * d -
            2.0 * std::cos(alpha - beta) +
            2.0 * d * (std::sin(alpha) - std::sin(beta));

        if (p_squared < 0.0) {
            return false;
        }

        p = std::sqrt(p_squared);

        double angle = std::atan2(
            std::cos(beta) - std::cos(alpha),
            tmp
        );

        t = mod2pi(-alpha + angle);
        q = mod2pi(beta - angle);

        return true;
    }

    bool dubinsRSR(
        double alpha,
        double beta,
        double d,
        double & t,
        double & p,
        double & q)
    {
        double tmp = d - std::sin(alpha) + std::sin(beta);

        double p_squared =
            2.0 +
            d * d -
            2.0 * std::cos(alpha - beta) +
            2.0 * d * (-std::sin(alpha) + std::sin(beta));

        if (p_squared < 0.0) {
            return false;
        }

        p = std::sqrt(p_squared);

        double angle = std::atan2(
            std::cos(alpha) - std::cos(beta),
            tmp
        );

        t = mod2pi(alpha - angle);
        q = mod2pi(-beta + angle);

        return true;
    }

    bool dubinsLSR(
        double alpha,
        double beta,
        double d,
        double & t,
        double & p,
        double & q)
    {
        double p_squared =
            -2.0 +
            d * d +
            2.0 * std::cos(alpha - beta) +
            2.0 * d * (std::sin(alpha) + std::sin(beta));

        if (p_squared < 0.0) {
            return false;
        }

        p = std::sqrt(p_squared);

        double angle = std::atan2(
            -std::cos(alpha) - std::cos(beta),
            d + std::sin(alpha) + std::sin(beta)
        ) - std::atan2(-2.0, p);

        t = mod2pi(-alpha + angle);
        q = mod2pi(-mod2pi(beta) + angle);

        return true;
    }

    bool dubinsRSL(
        double alpha,
        double beta,
        double d,
        double & t,
        double & p,
        double & q)
    {
        double p_squared =
            -2.0 +
            d * d +
            2.0 * std::cos(alpha - beta) -
            2.0 * d * (std::sin(alpha) + std::sin(beta));

        if (p_squared < 0.0) {
            return false;
        }

        p = std::sqrt(p_squared);

        double angle = std::atan2(
            std::cos(alpha) + std::cos(beta),
            d - std::sin(alpha) - std::sin(beta)
        ) - std::atan2(2.0, p);

        t = mod2pi(alpha - angle);
        q = mod2pi(beta - angle);

        return true;
    }

    bool dubinsRLR(
        double alpha,
        double beta,
        double d,
        double & t,
        double & p,
        double & q)
    {
        double tmp =
            (6.0 -
             d * d +
             2.0 * std::cos(alpha - beta) +
             2.0 * d * (std::sin(alpha) - std::sin(beta))) / 8.0;

        if (std::fabs(tmp) > 1.0) {
            return false;
        }

        p = mod2pi(2.0 * PI - std::acos(tmp));

        t = mod2pi(
            alpha -
            std::atan2(
                std::cos(alpha) - std::cos(beta),
                d - std::sin(alpha) + std::sin(beta)
            ) +
            p / 2.0
        );

        q = mod2pi(alpha - beta - t + p);

        return true;
    }

    bool dubinsLRL(
        double alpha,
        double beta,
        double d,
        double & t,
        double & p,
        double & q)
    {
        double tmp =
            (6.0 -
             d * d +
             2.0 * std::cos(alpha - beta) +
             2.0 * d * (-std::sin(alpha) + std::sin(beta))) / 8.0;

        if (std::fabs(tmp) > 1.0) {
            return false;
        }

        p = mod2pi(2.0 * PI - std::acos(tmp));

        t = mod2pi(
            -alpha -
            std::atan2(
                std::cos(alpha) - std::cos(beta),
                d + std::sin(alpha) - std::sin(beta)
            ) +
            p / 2.0
        );

        q = mod2pi(beta - alpha - t + p);

        return true;
    }

    double dubinsDistance(
        double start_x,
        double start_y,
        double start_theta,
        double goal_x,
        double goal_y,
        double goal_theta,
        double turning_radius)
    {
        double dx = goal_x - start_x;
        double dy = goal_y - start_y;

        double D = std::sqrt(dx * dx + dy * dy);
        double d = D / turning_radius;

        if (d < 1e-6) {
            return turning_radius *
                std::fabs(normalizeAngle(goal_theta - start_theta));
        }

        double theta = std::atan2(dy, dx);

        double alpha = mod2pi(start_theta - theta);
        double beta = mod2pi(goal_theta - theta);

        double best = std::numeric_limits<double>::infinity();

        double t;
        double p;
        double q;

        if (dubinsLSL(alpha, beta, d, t, p, q)) {
            best = std::min(best, t + p + q);
        }

        if (dubinsRSR(alpha, beta, d, t, p, q)) {
            best = std::min(best, t + p + q);
        }

        if (dubinsLSR(alpha, beta, d, t, p, q)) {
            best = std::min(best, t + p + q);
        }

        if (dubinsRSL(alpha, beta, d, t, p, q)) {
            best = std::min(best, t + p + q);
        }

        if (dubinsRLR(alpha, beta, d, t, p, q)) {
            best = std::min(best, t + p + q);
        }

        if (dubinsLRL(alpha, beta, d, t, p, q)) {
            best = std::min(best, t + p + q);
        }

        if (!std::isfinite(best)) {
            return D;
        }

        return best * turning_radius;
    }
};

}  // namespace bumperbot_planning

}
```

## 11. Parameter Explanation

### 11.1 `theta_bins_`

```cpp
int theta_bins_ = 72;
```

The planner searches in:

```cpp
x, y, theta
```

But `theta` is continuous.

So it is discretized into bins.

With:

```cpp
theta_bins_ = 72
```

each bin represents:

```cpp
360° / 72 = 5°
```

This means a heading of 0°, 5°, 10°, etc. maps into different bins.

Why this matters:

A car at the same position but facing a different direction is not the same state.

```cpp
cell = (10, 10), theta = 0°
cell = (10, 10), theta = 90°
```

These have different future possibilities.

---

### 11.2 `step_size_`

```cpp
double step_size_ = 0.25;
```

This is the distance traveled in one expansion.

Normal A*:

```cpp
move to next grid cell
```

Hybrid A*:

```cpp
simulate vehicle motion for 0.25 meters
```

Small step size:

```cpp
smoother paths
better accuracy
more computation
```

Large step size:

```cpp
faster planning
rougher paths
may skip narrow passages
```

---

### 11.3 `wheelbase_`

```cpp
double wheelbase_ = 0.5;
```

This is the vehicle wheelbase.

It appears in the bicycle model:

```cpp
theta_next = theta + ds / L * tan(delta)
```

where:

```cpp
L     = wheelbase
delta = steering angle
```

Larger wheelbase:

```cpp
wider turns
slower heading change
```

Smaller wheelbase:

```cpp
tighter turns
faster heading change
```

---

### 11.4 `max_steering_angle_`

```cpp
double max_steering_angle_ = 0.6;
```

This is the maximum steering angle.

```cpp
0.6 rad ≈ 34.4°
```

The planner allows:

```cpp
-0.6 rad
0.0 rad
+0.6 rad
```

These correspond to:

```cpp
right turn
straight
left turn
```

---

### 11.5 `min_turning_radius_`

```cpp
min_turning_radius_ = wheelbase_ / std::tan(max_steering_angle_);
```

This computes:

```cpp
R_min = L / tan(delta_max)
```

With:

```cpp
L = 0.5
delta_max = 0.6
```

we get:

```cpp
R_min ≈ 0.731 m
```

This is the smallest circle the robot can drive along.

Dubins paths need this radius.

---

### 11.6 Goal Tolerances

```cpp
double goal_xy_tolerance_ = 0.25;
double goal_theta_tolerance_ = 0.35;
```

Because Hybrid A* works in continuous space, it rarely lands exactly on the goal.

So the planner accepts the goal if:

```cpp
position_error < 0.25 m
heading_error < 0.35 rad
```

where:

```cpp
0.35 rad ≈ 20°
```

---

### 11.7 `directions_`

```cpp
std::vector<int> directions_ = {1};
```

This means forward-only.

Why?

Because Dubins assumes forward-only motion.

If reverse is required:

```cpp
std::vector<int> directions_ = {1, -1};
```

but then the better heuristic is Reeds-Shepp, not Dubins.

---

### 11.8 `steering_angles_`

```cpp
steering_angles_ = {
    -max_steering_angle_,
     0.0,
     max_steering_angle_
};
```

This creates three motion primitives:

```cpp
forward-right
forward-straight
forward-left
```

More steering angles produce smoother paths but increase branching factor.

## 13. Motion Simulation Explained

```cpp
HybridNode simulateMotion(
    const HybridNode & current,
    double steering_angle,
    int direction)
{
    double ds = direction * step_size_;

    double new_x = current.x + ds * std::cos(current.theta);
    double new_y = current.y + ds * std::sin(current.theta);

    double new_theta = current.theta +
        (ds / wheelbase_) * std::tan(steering_angle);

    new_theta = normalizeAngle(new_theta);

    GridNode grid_node = worldToGrid(new_x, new_y);

    HybridNode next(
        new_x,
        new_y,
        new_theta,
        grid_node.x,
        grid_node.y,
        thetaToBin(new_theta)
    );

    return next;
}
```

### 13.1 Distance Step

```cpp
double ds = direction * step_size_;
```

Since direction is `1`:

```cpp
ds = 0.25
```

The robot moves forward 25 cm.

---

### 13.2 Position Update

```cpp
new_x = current.x + ds * cos(current.theta);
new_y = current.y + ds * sin(current.theta);
```

If:

```cpp
theta = 0
```

then:

```cpp
cos(0) = 1
sin(0) = 0
```

So the robot moves along the positive x-axis.

If:

```cpp
theta = pi / 2
```

then:

```cpp
cos(pi/2) = 0
sin(pi/2) = 1
```

So the robot moves along the positive y-axis.

---

### 13.3 Heading Update

```cpp
new_theta = current.theta +
    (ds / wheelbase_) * tan(steering_angle);
```

This is the bicycle model.

If steering is zero:

```cpp
tan(0) = 0
```

so heading does not change.

If steering is positive, heading increases.

If steering is negative, heading decreases.

## 14. Collision Checking

### 14.1 State Validity

```cpp
bool isStateValid(double x, double y)
{
    GridNode grid_node = worldToGrid(x, y);

    if (!poseOnMap(grid_node)) {
        return false;
    }

    std::size_t cell = gridToCell(grid_node);

    if (cell >= map_->data.size()) {
        return false;
    }

    return map_->data.at(cell) == 0;
}
```

This checks whether a point is:

```cpp
inside the map
inside a free cell
```

The occupancy grid convention is usually:

```cpp
0    = free
100  = occupied
-1   = unknown
```

This implementation only accepts:

```cpp
0
```

as valid.

So unknown space is treated as invalid.

---

### 14.2 Motion Validity

```cpp
bool isMotionValid(
    const HybridNode & from,
    const HybridNode & to)
{
    int samples = 10;

    for (int i = 0; i <= samples; i++) {
        double t = static_cast<double>(i) / samples;

        double x = from.x + t * (to.x - from.x);
        double y = from.y + t * (to.y - from.y);

        if (!isStateValid(x, y)) {
            return false;
        }
    }

    return true;
}
```

This checks the motion segment between two states.

It samples points between `from` and `to`.

This avoids the problem where:

```cpp
start is free
end is free
but the motion crosses an obstacle
```

This is still simplified because it checks points, not the full robot footprint.

A production planner should check:

```cpp
robot footprint
inflated costmap
collision along curved arc
```

## 15. Dubins Distance Explained in Code

### 15.1 `mod2pi`

```cpp
double mod2pi(double angle)
{
    double result = std::fmod(angle, 2.0 * PI);

    if (result < 0.0) {
        result += 2.0 * PI;
    }

    return result;
}
```

This normalizes an angle to:

```cpp
[0, 2π)
```

Dubins formulas use this range.

---

### 15.2 `normalizeAngle`

```cpp
double normalizeAngle(double angle)
{
    while (angle > PI) {
        angle -= 2.0 * PI;
    }

    while (angle < -PI) {
        angle += 2.0 * PI;
    }

    return angle;
}
```

This normalizes an angle to:

```cpp
[-π, π]
```

This is useful for heading error.

Example:

```cpp
179° and -179°
```

Naively, the difference is:

```cpp
358°
```

But the real shortest angular difference is:

```cpp
2°
```

---

### 15.3 Dubins Local Variables

Inside `dubinsDistance`:

```cpp
double dx = goal_x - start_x;
double dy = goal_y - start_y;

double D = std::sqrt(dx * dx + dy * dy);
double d = D / turning_radius;

double theta = std::atan2(dy, dx);

double alpha = mod2pi(start_theta - theta);
double beta = mod2pi(goal_theta - theta);
```

Meaning:

| Variable   | Meaning                                  |
| ---------- | ---------------------------------------- |
| `dx`, `dy` | Vector from start to goal                |
| `D`        | Euclidean distance                       |
| `d`        | Distance normalized by turning radius    |
| `theta`    | Direction from start to goal             |
| `alpha`    | Start heading relative to goal direction |
| `beta`     | Goal heading relative to goal direction  |

Dubins formulas work in this normalized local frame.

---

### 15.4 `dubinsLSL`

```cpp
bool dubinsLSL(
    double alpha,
    double beta,
    double d,
    double & t,
    double & p,
    double & q)
{
    double tmp = d + std::sin(alpha) - std::sin(beta);

    double p_squared =
        2.0 +
        d * d -
        2.0 * std::cos(alpha - beta) +
        2.0 * d * (std::sin(alpha) - std::sin(beta));

    if (p_squared < 0.0) {
        return false;
    }

    p = std::sqrt(p_squared);

    double angle = std::atan2(
        std::cos(beta) - std::cos(alpha),
        tmp
    );

    t = mod2pi(-alpha + angle);
    q = mod2pi(beta - angle);

    return true;
}
```

`LSL` means:

```cpp
Left turn → Straight → Left turn
```

The function computes:

```cpp
t = first left-turn amount
p = straight segment length
q = final left-turn amount
```

If:

```cpp
p_squared < 0
```

then this Dubins word is invalid for the current start-goal configuration.

That does not mean the planner failed. It only means `LSL` is impossible, so the algorithm tries the other words.

---

### 15.5 Full Dubins Distance

```cpp
double dubinsDistance(...)
{
    ...
    double best = infinity;

    if (dubinsLSL(...)) best = min(best, t + p + q);
    if (dubinsRSR(...)) best = min(best, t + p + q);
    if (dubinsLSR(...)) best = min(best, t + p + q);
    if (dubinsRSL(...)) best = min(best, t + p + q);
    if (dubinsRLR(...)) best = min(best, t + p + q);
    if (dubinsLRL(...)) best = min(best, t + p + q);

    return best * turning_radius;
}
```

The function tries all six Dubins families and returns the shortest valid one.

This value becomes the Hybrid A* heuristic:

```cpp
h = Dubins distance from current pose to goal pose
```

## 16. Pruning by `(x, y, theta)`

Hybrid A* can generate many continuous states.

To control this, the planner discretizes each state into:

```cpp
grid_x, grid_y, theta_bin
```

Then it computes a unique index:

```cpp
index =
theta_bin * width * height +
grid_y * width +
grid_x
```

In code:

```cpp
std::size_t getHybridIndex(
    int grid_x,
    int grid_y,
    int theta_bin)
{
    return static_cast<std::size_t>(
        theta_bin * map_->info.width * map_->info.height +
        grid_y * map_->info.width +
        grid_x
    );
}
```

This means each grid cell has many heading layers.

Example:

```cpp
cell (10, 10), theta_bin 0
cell (10, 10), theta_bin 1
cell (10, 10), theta_bin 2
```

are different states.

The planner keeps the cheapest known way to reach each bucket:

```cpp
if (best_cost.find(new_index) == best_cost.end() ||
    new_node.cost < best_cost[new_index]) {
    best_cost[new_index] = new_node.cost;
    pending_nodes.push(new_node);
}
```

This is essential for performance.

## 17. Path Reconstruction

Each new node stores its parent:

```cpp
new_node.prev = std::make_shared<HybridNode>(active_node);
```

When the goal is reached, the planner walks backward:

```cpp
goal → parent → parent → start
```

Then reverses the path:

```cpp
start → ... → goal
```

The output is published as:

```cpp
nav_msgs::msg::Path
```

Each Hybrid A* node is converted to a ROS pose:

```cpp
geometry_msgs::msg::Pose hybridNodeToPose(const HybridNode & node)
{
    geometry_msgs::msg::Pose pose;

    pose.position.x = node.x;
    pose.position.y = node.y;

    tf2::Quaternion q;
    q.setRPY(0.0, 0.0, node.theta);
    pose.orientation = tf2::toMsg(q);

    return pose;
}
```

## 18. Comparison: A* vs Hybrid A*

| Feature        | A*                         | Hybrid A*                             |
| -------------- | -------------------------- | ------------------------------------- |
| State          | `(x, y)`                   | `(x, y, theta)`                       |
| Motion         | Grid moves                 | Kinematic motion                      |
| Expansion      | Neighbor cells             | Steering-based primitives             |
| Heuristic      | Manhattan / Euclidean      | Dubins / Reeds-Shepp / obstacle-aware |
| Path           | Grid path                  | Drivable path                         |
| Orientation    | Ignored                    | Included                              |
| Turning radius | Ignored                    | Included                              |
| Best for       | Point robots / simple maps | Car-like robots / autonomous driving  |

## 19. Dubins vs Reeds-Shepp

Dubins assumes:

```cpp
forward-only motion
```

Reeds-Shepp assumes:

```cpp
forward + reverse motion
```

So:

```cpp
Dubins heuristic → forward-only Hybrid A*
Reeds-Shepp heuristic → forward and reverse Hybrid A*
```

If reverse motion is added to the planner:

```cpp
std::vector<int> directions_ = {1, -1};
```

then Dubins is no longer the best heuristic. Reeds-Shepp becomes more appropriate.

## 21. Limitations of This Implementation

This implementation is useful for learning and interview preparation, but it is not yet a complete production planner.

### 21.1 No Analytic Expansion

A full Hybrid A* planner often tries to connect the current node directly to the goal using a Dubins or Reeds-Shepp curve.

This is called:

```cpp
analytic expansion
```

or:

```cpp
shot to goal
```

If the connection is collision-free, the planner terminates early.

This greatly improves performance.

The current implementation uses Dubins distance as a heuristic, but it does not yet generate the actual Dubins curve as a final connection.

---

### 21.2 Simplified Collision Checking

The code checks points along the segment.

A real robot has a footprint.

A better planner should check:

```cpp
robot radius
polygon footprint
inflation layer
costmap collision
arc collision
```

---

### 21.3 Forward-Only Motion

Because Dubins is used, the planner is forward-only.

This is suitable for many navigation tasks, but not ideal for parking or tight maneuvering.

For parking, reverse is often necessary.

That requires:

```cpp
Reeds-Shepp heuristic
reverse penalties
direction-switch penalties
```

---

### 21.4 No Obstacle-Aware Heuristic

Dubins distance ignores obstacles.

It estimates the best car-like path in open space.

In cluttered maps, a stronger planner may combine:

```cpp
Dubins / Reeds-Shepp non-holonomic heuristic
2D obstacle-aware grid heuristic
```

A common strategy is:

```cpp
h = max(h_nonholonomic, h_obstacle_aware)
```

This gives better guidance while preserving admissibility if both heuristics are admissible.

---

### 21.5 Resolution Dependency

The planner depends heavily on:

```cpp
map resolution
step size
theta bins
steering samples
goal tolerances
```

Poor tuning can cause:

```cpp
slow planning
rough paths
failure in narrow spaces
excessive pruning
inaccurate final heading
```

## 22. Practical Tuning Guidelines

### 22.1 `step_size_`

Use a step size close to the map resolution.

If the map resolution is:

```cpp
0.05 m
```

then a step size like:

```cpp
0.10 m to 0.25 m
```

may be reasonable.

Smaller step size gives better paths but slower planning.

---

### 22.2 `theta_bins_`

A good starting value:

```cpp
72 bins
```

This gives:

```cpp
5 degrees per bin
```

For faster planning, reduce it:

```cpp
36 bins
```

For better orientation accuracy, increase it:

```cpp
90 or 120 bins
```

---

### 22.3 Steering Angles

Three steering angles are simple:

```cpp
right
straight
left
```

More steering samples give smoother paths:

```cpp
{-0.6, -0.3, 0.0, 0.3, 0.6}
```

But more steering samples increase branching factor.

---

### 22.4 Goal Tolerance

For general navigation:

```cpp
goal_xy_tolerance_ = 0.25
goal_theta_tolerance_ = 0.35
```

may be acceptable.

For precise parking:

```cpp
goal_xy_tolerance_ = 0.05
goal_theta_tolerance_ = 0.05
```

may be needed.

But tighter tolerances make planning harder.

## 23. Key Interview Explanation

A strong interview answer:

> Hybrid A* extends classical A* by searching in SE(2), meaning `(x, y, theta)`, instead of only `(x, y)`. It uses vehicle motion primitives generated from a kinematic bicycle model, so each expansion is physically feasible for a car-like robot. The planner still uses `f = g + h`, but the heuristic can be non-holonomic, such as Dubins distance for forward-only motion or Reeds-Shepp distance when reverse is allowed. The algorithm is called hybrid because motion is simulated continuously, while visited-state pruning is done discretely using grid cells and heading bins.

---

## 24. Conclusion

Hybrid A* is the bridge between classical graph search and real vehicle motion planning.

Classical A* answers:

```cpp
How do I move from one grid cell to another?
```

Hybrid A* answers:

```cpp
How do I move from one pose to another while respecting vehicle kinematics?
```

The key transformation is:

```cpp
A* over (x, y)
```

to:

```cpp
Hybrid A* over (x, y, theta)
```

The most important components are:

```cpp
SE(2) state representation
bicycle model motion primitives
theta discretization
priority queue using f = g + h
Dubins heuristic for forward-only car-like motion
collision checking
cost pruning by grid cell and heading bin
path reconstruction through parent pointers
```

The result is a planner that produces paths much closer to what a real car-like robot can actually follow.

The essential idea is:

> Hybrid A* keeps the search intelligence of A*, but replaces unrealistic grid movement with kinematically feasible vehicle motion.
